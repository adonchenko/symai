# symai
The symai repository consists of the source code of the SymAI engine

Directories structure:
src is a subdirectory that contains the source code of modules
src/python is a sources those were written on python
src/python/server is a source subdirectory that consists of the source files and modules of backend server modules
src/python/bin/ is a directory that contains the binary executives those are used during constructing server modules
